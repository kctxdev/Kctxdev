## Como o CloudGuard funciona

```mermaid
%%{init: {'theme':'dark'}}%%
flowchart LR
    A[Evento na conta AWS] --> B[CloudTrail / GuardDuty]
    B --> C[EventBridge]
    C --> D[Lambda de resposta]
    D --> E[Instância isolada + evidência no S3]
    D --> F[Bucket S3 público → privado]
    D --> G[Tags de Centro de Custo aplicadas]
    D --> H[Recurso ocioso desligado]
    D --> I[Alerta via SNS]
```
